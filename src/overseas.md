## 凱旋門賞（河合厩舎・3歳・打診）

<span class="label label-verified">ダビスタ2で確認済み</span>（湯一路ページの整理・掲示板報告に基づく）

[湯一路「海外レース出走条件」](https://ds2.yublog.com/info/overseas.php) では、河合厩舎の **3歳**向けに **ルートC（未確定で検証中）** として次が挙げられています。

| 条件（湯一路の記載） |
| --- |
| 馬齢が3歳 |
| **日本ダービー**に勝利 |
| **3歳以上・芝2000m以上のGI**に勝利（**皐月賞・オークス・宝塚記念**） |
| 上記に加え、芝2000m以上のGI **または** 3歳GII（弥生賞ディープ記念・青葉賞・フローラステークス・京都新聞杯） |

同ページの掲示板では、**日本ダービー以外の芝2000m以上GI**（皐月賞・オークス・宝塚記念のいずれか）と **芝2000m以上GII** の組み合わせで打診された例が報告されています（No.302 など）。**宝塚記念が必須か**は掲示板 No.273 に「同年の宝塚記念に勝たなくても他条件をクリアしていればOKなど」とある一方、**ダービー＋宝塚のみでは不可**の報告（No.284 など）もあり、**確定条件ではない**。

**簡略イメージ（湯一路ルートCの要約）:** 河合厩舎の3歳馬が **日本ダービー** を勝ち、さらに **皐月賞・オークス・宝塚記念のいずれか**（およびページ記載のGII条件）を満たすと打診される、という整理。2つ目のGI（皐月賞／オークス／宝塚記念）の**どれが必須か・宝塚が不要なケースがあるか**は、同ページでも**検証中**です。

出典: [湯一路 overseas.php](https://ds2.yublog.com/info/overseas.php)
