## 用語（同ツールの説明に基づく）

| 用語 | 内容（要約） |
| --- | --- |
| 面白い配合 | 同ツール上の配合評価の一種 |
| 凝った配合 | 同ツール上の配合評価の一種 |
| 完璧な配合 | 「面白い配合」と「見事な配合」の両方が成立する状態。同ツールの説明では、これに**追加ボーナスはない** |

## ルート例（同ツール）

### NT → Monsun → ガリレオ

同ツールによると、次の血統配置になる例がある。

| 項目 | 内容 |
| --- | --- |
| 血統 | Lady Angela **5×5**、Northern Dancer **3×4** |
| 評価 | 面白い配合・凝った配合 |
| 起始繁殖牝馬 | **ドバイマジェスティ**・**アクトレス**・**カルティカ**・**マルターズヒート**のみが条件を満たす（同ツール） |

### キンカメ → Monsun → ガリレオ

同ツールによると、**完璧な配合**になるのは起始牝馬が **シルヴァーグレイル** の場合のみ。

### ドバイマジェスティ × マルゼンスキー → その牝馬子 × ガリレオ

同ツールによると、面白い配合・凝った配合となり、Buckpasser **5×4**、Northern Dancer **3×4** の配置例がある。

## 自家繁殖ガリレオ牝馬からの「完璧」

同ツールの整理（要約）:

| 世代数 | 完璧な配合の可否 |
| --- | --- |
| 1世代 | **不可能** |
| 2世代 | 母の父が **Monsun**・**ノヴェリスト**・**カルストンライトオ**・**シンボリルドルフ**のいずれかの場合のみ可能 |
| 3世代（例） | Monsun または ノヴェリスト → クリエイターII → **ゴールドシップ** / **コントレイル** / **オルフェーヴル** / **カラヴァッジオ** / **ドリームジャーニー** |
| 3世代（例） | シンボリルドルフ → ヘニーヒューズ → **パドトロワ** |
